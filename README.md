# CounselingNow

透過多元命理方法分析您的諮商時機與適合的治療取向。

## 目前進度

- 目前支援 7 種方法：紫微斗數、八字四柱、易經、塔羅、西洋占星、吠陀占星、數字命理
- 已具備結果整合流程，可搭配諮商時機判斷與取向推薦一起使用

## 功能特色

- 🔮 **多元命理分析**：整合 7 種命理方法，支援中西系統交叉參考
- ⏰ **諮商時機判斷**：分析目前是否適合開始諮商
- 🎯 **取向匹配推薦**：根據五行特質推薦適合的諮商取向
- 🤖 **GPT 提示詞整合**：結果頁提供 GPT 提示詞預覽、複製與開啟 ChatGPT
- 📄 **結果匯出**：結果頁可將分析內容匯出保存
- 🌐 **多語系介面**：內建中文與英文切換
- 🔒 **隱私保護**：純前端運算，出生資料不上傳伺服器

## 技術棧

- **框架**：React + TypeScript + Vite
- **樣式**：Tailwind CSS
- **狀態管理**：Zustand
- **紫微斗數**：[iztro](https://github.com/SylarLong/iztro)
- **塔羅**：Tarot Card API

## 快速開始

使用 `npm` 作為套件管理器。

```bash
# 安裝依賴
npm install

# 開發模式
npm run dev

# 執行測試
npm test -- --run

# 建置生產版本
npm run build
```

## 五行-諮商取向對應

### 木（成長、疏通、運動、彈性、調節）

- TRE 創傷釋放運動
- SMART 感官律動調節
- 遊戲治療
- 內在家庭系統治療 (IFS)

### 火（情緒、轉化、創造、象徵、意義）
- 榮格心理學
- 藝術治療
- 敘事治療
- 情緒焦點治療 (EFT)

### 水（情緒、潛意識、流動、覺察、依附）
- EMDR
- 音樂治療
- 精神分析取向
- 出生與出生前心理學
- 正念治療
- 催眠治療

### 土（穩定、結構、承載、養分、關係）
- 阿德勒心理學
- 薩提爾成長模式
- 基模治療

## 專案結構

```
CounselingNow/
├── src/
│   ├── modules/          # 7 種命理方法模組
│   ├── analysis/         # 時機與取向分析引擎
│   ├── components/       # 表單、結果區、匯出與切換元件
│   ├── i18n/             # 多語系設定與 locales

│   ├── utils/            # GPT 提示詞、匯出、剪貼簿等工具

│   ├── types/            # 共用型別
│   └── test/             # 測試設定
├── docs/
│   └── plans/            # 設計文件
└── package.json
```
